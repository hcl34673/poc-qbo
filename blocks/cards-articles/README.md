# cards-articles

Custom **cards** block. Purpose: A grid of related-article cards, each with an image, category tag, title and date, linking to another article..

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: repeating rows — one per card — each with an image cell and a body cell (tag, title link, date).

## Supported variations

No variations.

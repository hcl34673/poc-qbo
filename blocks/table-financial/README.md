# table-financial

Custom **table** block. Purpose: A two-column financial data table (line item to value) with an optional bold caption, used for a cash flow statement example..

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: an optional single-cell caption row, followed by repeating two-cell rows of line item and value.
